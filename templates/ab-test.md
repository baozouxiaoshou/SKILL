## 样本量计算

### 基础参数
- 基线转化率：X%
- 期望提升：+Y%
- 显著性水平：α = 0.05（95% 置信）
- 统计功效：1-β = 0.80

### 样本量公式（简化）
```
n = 16 * p * (1-p) / (delta^2)
```
详见：https://www.optimizely.com/sample-size-calculator/

### 实验周期
- 最小样本：每个组 [N] 用户
- 覆盖完整业务周期：至少 7 天（含工作日 + 周末）
- 警惕新用户涌入导致样本膨胀

## 决策规则

### 提前停止
- ❌ **禁止**：看到正向后立刻停止（可能是偶然）
- ✅ **允许**：达到预设样本量 + 显著差异 + 业务 OK 后停止
- ⚠️ **慎重**：实验周期 < 7 天或样本量不足

### 显著性判定
- p-value < 0.05 视为显著
- 95% 置信区间不包含 0

### 决策矩阵

| 结果 | 后续动作 |
|------|---------|
| 实验组显著正向 | 全量上线 |
| 实验组显著负向 | 保留旧版 |
| 无显著差异 | 保留旧版（避免无谓变更） |
| 边界显著 | 扩大样本或保守上线 |
