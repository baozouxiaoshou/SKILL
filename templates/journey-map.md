## Mermaid 旅程图（图形化表达）

```mermaid
flowchart LR
    A[认知:用户<br/>触达场景] --> B{考虑:<br/>对比评估}
    B -->|感兴趣| C[使用:<br/>首次体验]
    B -->|不感兴趣| X[流失]
    C --> D{满意?}
    D -->|是| E[留存:<br/>持续使用]
    D -->|否| Y[流失]
    E --> F{核心需求<br/>被满足?}
    F -->|是| G[分享:<br/>推荐他人]
    F -->|否| Z[流失]
    
    style A fill:#e3f2fd
    style C fill:#fff3e0
    style E fill:#e8f5e9
    style G fill:#fce4ec
    style X fill:#ffebee
    style Y fill:#ffebee
    style Z fill:#ffebee
```

## 自检问题
- [ ] 是否覆盖了完整旅程（认知 → 流失）？
- [ ] 痛点是否具体可感知（不是"用户体验差"这种笼统说法）？
- [ ] 机会点是否可执行（不是"提升满意度"）？
- [ ] 情绪曲线是否符合真实用户感受？
